## 2026-07-01 - Optimizing LCP and Fixing Asset 404s
**Learning:** In a repository with many assets named with spaces (e.g., "SIN FIN - BATALLANDO.mp4"), manual URI encoding in the HTML source is critical to prevent 404 errors, as some browser environments or simple static servers do not automatically handle raw spaces in `src` attributes. Additionally, identifying the true LCP element (here, `Batallando6.png`) and explicitly setting `fetchpriority="high"` and `loading="eager"` provides a measurable boost to perceived load performance.
**Action:** Always perform a recursive directory search (`ls -R`) to verify asset locations against the HTML source, and ensure all asset paths are URI-encoded and relative to the project root. Prioritize `fetchpriority` for the main hero image and brand identifiers.
