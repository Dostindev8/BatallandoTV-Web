## 2026-08-04 - [Fixing 404 Video Errors & Optimizing Below-The-Fold Preloading]
**Learning:** Hardcoded asset paths pointing to missing legacy directories (like `images/`) cause 404 errors during page initialization, blocking or delaying visual execution. Furthermore, below-the-fold media assets (like looping news card videos) that are not critical for above-the-fold Largest Contentful Paint (LCP) should always be set to `preload="none"` to drastically reduce upfront download size and prevent network connection queue congestion.
**Action:** Always inspect the console and network panel during initialization to detect and correct 404 paths to valid relative assets, and aggressively set non-critical/below-the-fold media elements to `preload="none"` or `preload="metadata"`.
