## 2026-11-06 - Fixing 404 Video Source Prevents 3000ms Fallback Delay in Intro
**Learning:** In this codebase, the full-screen 3D intro overlay relies on the `#bb-vbg` video `canplay` event to trigger `revealIntro()`. When the media path returns a 404 error (e.g. referencing `images/SIN_FIN_-_BATALLANDO.mp4` instead of `assets/Batallando/SIN%20FIN%20-%20BATALLANDO.mp4`), the video never triggers `canplay` and instead incurs a hardcoded 3000ms fallback timeout before the intro reveals, delaying interactive UI display by over 3 seconds and wasting network overhead on failed requests.
**Action:** Always verify that media asset paths in static video tags point to valid URIs under `assets/Batallando/` with proper URL encoding (`%20` for spaces) so media events fire immediately without hitting fallback timeouts.
