## 2026-05-03 - Resource Prioritization & 404 Prevention
**Learning:** In a static HTML page without a build pipeline, resource discovery delays can severely impact the Largest Contentful Paint (LCP). Additionally, 404 errors for media and critical LCP assets (like the background intro video or the main hero image) trigger browser request retries and block rendering paths. Standardizing resource hints (`preconnect` to external CDNs like cjs), preloading above-the-fold assets, and preventing decode delays by avoiding `decoding="async"` on LCP candidates while aggressively lazy-loading below-the-fold elements dramatically reduces time-to-interactive (TTI) and LCP.
**Action:** Always preconnect to external CDNs with `crossorigin`, preload high-priority above-the-fold assets, replace invalid/404 assets with correct URI-encoded relative paths, use standard video preload configurations, and avoid `decoding="async"` specifically on LCP candidates.
