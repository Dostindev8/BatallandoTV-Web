## 2026-05-04 - Fix 404 on Video Background to Bypass 3000ms Fallback Delay
**Learning:** In `index.html`, the background video element `#bb-vbg` had `<source src="images/SIN_FIN_-_BATALLANDO.mp4">`, which returns a 404 because the file is located at `assets/Batallando/SIN FIN - BATALLANDO.mp4`. Because the video failed to load, the `canplay` event never fired on the video, causing the intro script to wait for the entire 3000ms safety fallback timeout before revealing the intro animations.
**Action:** When working with intro video preloads and video backgrounds, verify that media paths accurately reference existing assets in `assets/Batallando/` with URI encoding (`%20` for spaces). This allows `canplay` to trigger as soon as metadata/first frames buffer (~993ms vs ~3000ms timeout), saving ~2s on intro readiness.
